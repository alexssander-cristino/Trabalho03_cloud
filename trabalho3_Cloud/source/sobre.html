Tema

Sistema de Monitoramento de Segurança

Descrição

Este projeto foi desenvolvido para a disciplina de Cloud Computing com o objetivo de simular um ambiente Linux utilizado por uma central de monitoramento de segurança.

A solução utiliza Docker para criação do ambiente containerizado, Apache para publicação da aplicação web e Shell Script para automação de tarefas operacionais como deploy, backup, monitoramento, controle de permissões e geração de relatórios.

Tecnologias Utilizadas

  • Ubuntu Server
  • Docker
  • Docker Compose
  • Apache
  • Shell Script
  • GitHub
  • DockerHub
